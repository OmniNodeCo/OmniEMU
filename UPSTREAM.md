# Upstream provenance

OmniEMU's Nintendo Switch emulation implementation was imported from the MIT-licensed Ryujinx source tree.

- Source mirror: `https://github.com/nintendoswitchemulators/ryujinx.git`
- Imported commit: `a2c003501371463fd1f98d2e5a7602ae19c21d7c`
- Upstream commit date: 2024-10-01
- License: MIT (`LICENSE.txt`)

The source mirror was used because the current Ryubing Forgejo server was unavailable from the build environment at import time. Original namespaces and copyright notices are intentionally retained for attribution and to keep upstream changes auditable.

No firmware, encryption keys, title keys, games, or proprietary Nintendo SDK components are included.
